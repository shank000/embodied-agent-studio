配置 2–8 个决策器，每项可使用独立的 TypeSafe 或自定义服务；kind、url、model、vision、question_name、timeout_s、weight 均按接口配置。weight 是投票权重，须大于 0。

索引从 0 开始，密钥仅发送到对应服务。此字段只存后端内存，发送后清空，不写入方法配方。

编辑已冻结的模型、技能与控制参数

VISUAL ROBOT AGENT
每轮观察，再执行一步。
选择模型并填写任务，Agent 会读取前方、侧方、腕部三张同步图像和机械臂状态，输出世界坐标系下的绝对末端位姿。IK 在本地求解，MuJoCo 执行器完成动作。
  • 默认复用本机 Codex CLI 登录；模型配置也支持 API 接入。
  • “仅执行一轮”适合轻量测试；连续接管会在每次动作后重新观察。
  • 停止接管、暂停、重置或切换机械臂会取消当前模型请求。
  • SO-101 只有 5 个机械臂自由度，不可达位姿将返回给模型调整。
  • 任务完成标记为模型判断；实际位置误差单独显示。
模型输入不包含物体真实坐标、物体 6D 位姿、关键点或 3D value map。接触和物体运动由 MuJoCo 计算。当前控制器使用局部 IK 与关节插值，不包含避障路径规划。仅连接本机仿真。
