# EmbodiWorks 品牌与媒体

**EmbodiWorks · 具身工坊**，面向具身 Agent、策略组合与实验的开放工作台。仓库地址和 `embodied-*` 接口协议名称保持不变。

Logo 使用开放工位轮廓和相连关节：两侧括形对应共享仿真环境，中间节点对应可组合的模型与执行链。采用森林绿与透明背景，可单色印刷和无损缩放。

[工作台](images/workbench.jpg)、[组合研究](images/research.jpg)与[轨迹分析](images/experiments.jpg)均采集自实际网页界面。研究图展示配置状态，没有生成虚构的评测数据；分析图展示一条真实运行的已记录视频与调用曲线。画面用于介绍操作流程，不用作模型性能比较结论。
