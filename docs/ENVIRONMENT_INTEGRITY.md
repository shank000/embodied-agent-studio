# 仿真环境完整性检查

检查日期：2026-10-30。本报告覆盖现有 10 个非 RoboDojo 后端；RoboDojo 的接入与原生验收见 [RoboDojo 文档](robodojo.md)。本次使用独立测试进程，未切换或重启用户正在使用的 8000 服务，未调用收费模型。

## 当前结论

MuJoCo 的原生物理、图像、控制、自由视角及任务判定检查通过；ALFWorld 文字环境的原生交互、回放及六类任务的官方示范检查通过。其余引擎具有实现和测试入口，但本次不能把它们全部标为原生运行通过。

LIBERO 原生测试在创建 MuJoCo 模型时遇到 `Could not allocate memory`，测试主体尚未执行。同期机器可用物理内存约 2.10 GiB、可提交内存约 2.83 GiB、内存负载 86%，GPU 可用显存约 3.30 GiB。为保留正在运行的工作台和用户应用，本次停止继续启动其他大型原生渲染环境；没有反复重试 OOM，也没有终止其他应用释放资源。完整 Isaac Sim 运行时未安装。

**安装检查、适配契约通过和真实环境运行是三个不同验收层次。** 8 个可选环境的独立解释器能够启动并找到对应 SDK；这不等于 Unity、Vulkan、RTX、资源加载和动作执行已经通过。本次的程序日志与机器可读结果位于 [本次证据目录](../artifacts/validation/environment-integrity-20261030/)；此前文档中的原生验收记录不计作本次重测。

## 接口完整性与实际限制

连续控制后端实现了场景重置、观测、渲染、控制、完成判定、检查点、轨迹回放和关闭等平台接口。共同的进程桥接承担渲染传输、超时和生命周期管理；本次通过契约测试检查这些公开边界，不能因此推出每个 SDK 内部原生路径均正确。

- **任务和动作必须按后端能力选择。** 本次发现目录此前为 LIBERO 多声明了 `instruction`，为 RoboCasa365 多声明了 `instruction` 和 `home`。现已从各后端实际 `CAPABILITIES` 取值，并验证目录不再宣称这些不支持的命令。RoboCasa 的原生命令是归一化控制量，不能解释成 12 个关节角度。
- **家务环境有独立动作语义。** ALFWorld / THOR 系列用离散环境步骤计时，不提供连续 TCP 或关节 VLA 接口。ALFWorld 文字预览是文字界面；视觉需求应选择 ALFWorld · 视觉。它们的检查点通过原始 episode 和动作重放恢复，并校验恢复后的状态。
- **任务完成由环境决定。** 模型声明成功不能覆盖原生判断。本次 MuJoCo 正例通过设置已打开的抽屉作为判定夹具，随后执行真实物理保持来验证评价器；这证明判定链路有效，不代表模型或控制器完成了拉抽屉任务。ALFWorld 正例使用官方示范，仅作为环境接口与原生判定的验收输入。
- **资产与场景范围应分别统计。** RoboCasa 公开完整任务目录，当前适配的布局 / 风格选择仍是固定子集；AI2-THOR 是 4 房间的任务模板。Genesis 和 Isaac 桌面任务是平台自定义任务，不能与官方完整 benchmark 的成绩混称。
- **实验数据隔离已有回归。** 共同测试覆盖后端 / 版本 / 评价器 / 机器人 / 场景 / 任务身份、跨环境检查点拒绝、旧动作拒绝、划分中官方初始状态重复识别、分析时不同引擎分组。种子不同不保证从有限官方状态池抽取到不同初始状态。

## 下一次原生验收

在停止不需要的本机工作负载、具备足够内存后，按单一引擎串行执行现有 native tests，禁止同时启多个 GPU 后端。顺序可从 LIBERO 重新开始，再到 ManiSkill、Genesis、RoboCasa365、ALFWorld · 视觉、AI2-THOR、Isaac Lab / Newton。完整 Isaac Sim 需准备对应独立运行时和资产。

每个环境至少保存一条代表 episode 的下列证据：原生加载 / 重置、非空图像或明确文字观测、可见状态小动作、原生成功与失败样例、检查点恢复、轨迹与视频、停止和关闭。测试环境可以用特权状态构造评价器正反样例，模型策略不得读取这些验收夹具。失败必须保留原生错误、当前后端和资源快照；不能静默切回 MuJoCo 或用预览图宣称原生渲染成功。

完整任务集的成功率、真实模型控制质量和长期连续运行稳定性需要独立实验，均不在本次轻量集成检查的通过结论内。
